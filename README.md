# تطبيق جوال ركاز (Rikaz Mobile App)

تطبيق الجوال الرسمي لمنصة ركاز لإدارة المدارس مبني باستخدام **React Native** و **Expo** و **TypeScript**.

## المميزات المطبقة:
1. **شاشة تسجيل دخول موحدة تدعم الـ RTL بالكامل**:
   - **بوابة الطالب**: الدخول برقم الهوية/الإقامة ورقم C-Smart.
   - **بوابة ولي الأمر**: الدخول برقم الهوية ورمز التحقق (OTP) عبر واتساب.
   - **بوابة الإدارة والموظفين**: الدخول برقم الهوية ورمز التحقق (OTP) أو اسم المستخدم وكلمة المرور.
2. **قواعد التحقق والأمان**:
   - تطبيق عداد زمني 60 ثانية لإعادة إرسال الرمز وحدود المحاولات لمنع السبام.
   - معالجة لوحة المفاتيح التلقائية وتجاوبها للأجهزة المختلفة (Android و iOS).
   - منع تكرار النقر وإرسال الطلبات أثناء التحميل.
3. **إدارة الجلسات والتخزين الآمن**:
   - حفظ الجلسة واستعادتها عبر `expo-secure-store`.
   - تجديد الجلسة تلقائياً (`autoRefreshToken`).
4. **تعدد المدارس والأدوار (Context Switching)**:
   - بعد تسجيل الدخول، يتم استعراض العضويات التابعة للحساب.
   - إمكانية تبديل الفرع والمدرسة والدور عبر استدعاء `set_active_context`.
   - مسح وتفريغ كاش الصلاحيات والبيانات السابقة كلياً عند التبديل (Zero-leakage).
5. **الصلاحيات المرنة (Flexible Permissions)**:
   - الاستعلام عن `perm_my_school` لكل فرع لعرض الصلاحيات الفعلية للحساب وعدم الاكتفاء بالدور الأساسي.

## التشغيل والمعاينة على الجوال:
```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير
npx expo start
```
- لمستخدمي **Android**: مسح رمز الاستجابة السريعة (QR Code) باستخدام تطبيق **Expo Go**.
- لمستخدمي **iOS**: مسح الرمز باستخدام تطبيق الكاميرا لفتحه في **Expo Go**.
